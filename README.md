# Black Swan — Daily Convergence Monitor
## Setup & Daily Workflow Guide

---

## Files in this package

| File | Role |
|---|---|
| `black_swan_dashboard_v2.html` | The dashboard — open in browser each morning |
| `bswan_fetcher.py` | Python script that fetches live data and writes `daily_readings.json` |
| `daily_readings.json` | Today's readings — auto-generated by fetcher, read by dashboard |
| `bswan_setup.sh` | **macOS / Linux** one-time setup script |
| `bswan_setup.bat` | **Windows** one-time setup script |
| `bswan_fetcher.log` | Auto-created log of each fetch run |

All five files must live in the **same folder**.

---

## One-time setup (5 minutes)

### macOS / Linux
```bash
chmod +x bswan_setup.sh
./bswan_setup.sh
```

### Windows (run as Administrator)
```
bswan_setup.bat
```

The setup script will:
1. Install Python dependencies (`requests`, `yfinance`, `schedule`)
2. Ask for your free FRED API key (get one at https://fred.stlouisfed.org/docs/api/api_key.html)
3. Register a **7:00am Mon–Fri cron/Task Scheduler job**
4. Run the fetcher once immediately so you have data right away

---

## FRED API key (free, takes 30 seconds)

Go to: https://fred.stlouisfed.org/docs/api/api_key.html

FRED powers three of the most critical auto-fetched indicators:
- `T10YIE` — 10-year breakeven inflation
- `DGS10` — 10-year nominal Treasury yield
- `BAMLH0A0HYM2` — ICE BofA US High Yield OAS

Without the key, these three fields carry forward yesterday's values.

## How daily refresh works

```
07:00 AM  ──►  bswan_fetcher.py runs (cron / Task Scheduler)
                │
                ├── Fetches WTI, crack spread, VIX from yfinance
                ├── Fetches breakevens, 10y yield, HY OAS from FRED
                ├── Fetches bid-to-cover from TreasuryDirect
                ├── Checks WHO RSS for pandemic tier
                └── Writes  daily_readings.json

07:00+ AM  ──►  You open black_swan_dashboard_v2.html
                │
                └── Browser fetches daily_readings.json automatically
                    (via local HTTP server — see below)
                    Shows freshness banner: ✦ green = fresh today
```

### Serving via local HTTP server (required for auto-load)

Browsers block `file://` fetches for security. Run a one-line local server:

**macOS / Linux:**
```bash
cd /path/to/bswan/folder
python3 -m http.server 8080
```
Then open: **http://localhost:8080/black_swan_dashboard_v2.html**

**Windows:**
```
cd C:\path\to\bswan\folder
python -m http.server 8080
```

Add `http://localhost:8080/black_swan_dashboard_v2.html` to your browser bookmarks. 
Open it each morning — the JSON auto-loads and the freshness banner confirms.

> **Without the local server:** The dashboard still works — it falls back to 
> the last manually saved snapshot or the hardcoded baseline. All manual 
> entry and Save/Load functions work in `file://` mode.

## Manual fetch (any time)

Run the fetcher outside of the scheduled time:

```bash
# macOS / Linux
FRED_API_KEY=your_key python3 bswan_fetcher.py

# Windows
set FRED_API_KEY=your_key
python bswan_fetcher.py
```

Or use daemon mode (runs continuously, fires at 07:00 each day):
```bash
python3 bswan_fetcher.py --daemon
```

## What each auto-fetched indicator uses

| Dashboard field | API / source | Ticker / series |
|---|---|---|
| WTI crude | yfinance | `CL=F` |
| Crack spread (proxy) | yfinance | `HO=F` heating oil minus `CL=F` |
| 10y breakeven inflation | FRED | `T10YIE` |
| HY OAS | FRED | `BAMLH0A0HYM2` |
| 10y UST yield | FRED | `DGS10` |
| Term premium (proxy) | FRED | `DGS10` minus `T5YIE` |
| MOVE index (proxy) | yfinance `^VIX` | VIX × 2.1 + 90 |
| Auction bid-to-cover | TreasuryDirect REST API | 10y Note latest auction |
| Pandemic tier | WHO Disease Outbreak News RSS | keyword scoring |

> **MOVE proxy note:** The ICE BofA MOVE index requires a paid subscription.
> The VIX-based proxy directionally tracks MOVE; for precision, subscribe to
> ICE indices or Bloomberg and replace `move_proxy()` in the fetcher.

## Troubleshooting

**Dashboard shows stale data / orange banner**
→ Check `bswan_fetcher.log` for errors. Most common: FRED key missing or expired.

**Cron not running**
→ `crontab -l | grep bswan` — if empty, re-run `bswan_setup.sh`
→ macOS: check System Settings → Privacy → Full Disk Access for cron

**yfinance returns empty data**
→ yfinance occasionally breaks when Yahoo Finance changes its API. Run:
  `pip install --upgrade yfinance`

**Windows Task Scheduler not firing**
→ Open Task Scheduler UI → BlackSwanMonitor → Run manually to test
→ Check "Run only when user is logged on" vs "Run whether or not logged on"
